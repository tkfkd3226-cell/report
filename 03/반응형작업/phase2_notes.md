# 반응형 2차 — 재계약 검토

## 적용 파일
index.html, style.css, common.js. 세 파일은 1차 내용을 포함한 누적 수정본이다.

## 변경
- 반영 현황: 기존 표 DOM과 9개 행 유지. 의미별 열 class와 data-label 추가. 1440px 이하에서는 fixed layout과 반영사항 25% 배분, 반영내용은 잔여폭 사용. 760px 이하에서는 행 하나를 카드 하나로 표시.
- 주요 변경 요약: 기존 8개 카드 유지. Web에서는 실제 컨테이너 폭 1200px 이하 3열, 900px 이하 2열. 그 이상 4열. Tablet/Phone은 2열. 900px 기준은 사이드바가 있는 좁은 Web에서 카드당 읽기 폭을 확보하기 위한 component 기준이며 viewport breakpoint가 아니다.
- Contract Diff: 공유 반영내용 track 토큰으로 제목/파일명/내용 열을 정렬. Wide Web은 360px 유지, 1440px 이하 Web은 세 영역 같은 비율.
- 1100px 이하에서는 기존 제목과 셀을 조항별 종전 전체 → 재계약 전체 → 반영 내용으로 이동한다. 내용 DOM을 복제하지 않는다. 원래 row와 셀 참조를 유지하여 Web 복귀 시 159쌍의 semantic row alignment를 복원한다.
- 작은 화면에서도 문단의 기존 변경/동일 배경을 유지한다. 원본 파일명/부속합의서 안내는 세로 배치하여 보존한다.
- beforeprint 및 print media 전환에서는 원래 Web DOM으로 복원하고 이후 현재 화면 구간으로 돌아온다.
- Phone 글자 크기와 카드 여백은 기존 dash 토큰을 사용한다. CSS는 Contract 책임 영역 안에 배치했다.

## 보존
계약 문구, PDF 링크, Diff 24개(변경 17/동일 7), 초기 접힘, 전체/변경 필터, 사업성 계산, 정산 데이터, 1차 메뉴 및 스냅샷 처리.
Wide Web 표는 기존 자동 열 배분을 유지하여 1920px 기준 영향 최소화. 실제 픽셀 일치는 미검증이다.

## 검증 결과
- node --check 통과.
- HTML 문구 비교: 추가한 종전계약/재계약안 구분 라벨 외 원문 텍스트 동일.
- 중복 ID 0, 버튼 type 누락 0, 깨진 aria-controls 0.
- CSS !important 0, 미사용 custom property 0, 동일 조건 내 동일 selector 블록 중복 0, 중첩 블록 검사 통과.
- 실제 첨부 HTML에서 추출한 24개 조항의 159쌍 셀을 대상으로 이동/복원 모의 실행 통과.
- Web → 작은 화면 → 인쇄 → 작은 화면 → Web을 5회 반복하여 노드 동일성, 순서, wrapper 중복 없음 확인.
- 기존 펼침/필터 코드 변경 없음 확인.
- 계산 엔진 12/12, 정산 데이터 검증, 1차 메뉴 모의 실행 통과.

## 실기 미검증 및 확인 항목
현재 환경에 브라우저 실행 파일이 없어 화면 실측/픽셀 비교를 하지 못했다. 정적 검사는 실기 통과를 의미하지 않는다.
- 1920px: 기존 표 폭 배분과 Diff 열 정렬 유지 확인.
- 1440/1280/1101px: 반영 현황 줄바꿈, 주요 변경 요약 열 수, Diff 동일 비율 확인.
- 1100/761px: Diff를 펼쳐 종전 전체 → 재계약 전체 → 반영 내용 순서 확인.
- 760/390px: 반영 현황 카드, 요약 2열, PDF 버튼/범례 줄바꿈, 긴 URL/부속표 가로 넘침 확인.
- 펼친 상태에서 1101↔1100 전환과 인쇄 전후에 문단 누락/중복 없는지 확인.
- 사업성/정산의 기존 내부 고정폭은 3~5차 대상이므로 전체 페이지 가로 넘침 해소는 아직 완료로 판정하지 않는다.
